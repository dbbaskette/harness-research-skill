# Source strategy routing

Load only the strategy matching this question. Technical claims use primary
sources for support; community reports may reveal problems or research leads.
Root scope/privacy limits apply to every strategy. Fixed query quotas and source
lists in retained upstream guidance are suggestions; use the sources needed.

| Need | Strategy |
| --- | --- |
| Product comparison or practices | [General web](../upstream/codex/agents/web-search-modules/general-web.md) |
| Bugs, regressions and maintainer issues | [GitHub debugging](../upstream/codex/agents/web-search-modules/github-debug.md) |
| Papers and academic evidence | [Academic papers](../upstream/codex/agents/web-search-modules/academic-papers.md) |
| Technical questions | [Technical Q&A](../upstream/codex/agents/web-search-modules/stackoverflow.md) |
| Chinese language technical sources | [Chinese communities](../upstream/codex/agents/web-search-modules/chinese-tech.md) |
