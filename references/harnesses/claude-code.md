# Claude Code native research workers

Read only when coordinating research inside Claude Code. Keep this coordinating
skill in the main conversation and use native subagents exposed by that session.
The official [subagent guide](https://code.claude.com/docs/en/sub-agents) describes
the Agent tool, isolated contexts, tool access and result handling. Use the session’s
actual interface rather than assuming a fixed tool spelling or installed custom role.

Launch at most three independent investigators within configured capacity. Include
the settled brief, assigned questions, source restrictions, isolated working
directory and [packet contract](../investigation-packet.md) in each delegation.
Register actual returned invocation identities before accepting their evidence.
A worker must not author shared case state or choose its reviewer identity.

A separate invocation reviews the saved final dossier. A forked skill alone does
not define this coordinating workflow. Do not install agent definitions, broaden
permissions or start `claude` subprocesses to bypass unavailable native delegation.
Use sequential investigation when needed; without a permitted separate reviewer,
keep the report draft. Use only supported cancellation/resume operations and record
limitations. This guidance does not establish live Claude Code acceptance.
