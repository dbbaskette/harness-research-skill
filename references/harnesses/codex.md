# Codex native research workers

Read only when coordinating research inside Codex. Use the delegation operations
advertised by the current session; their names and availability are host-specific.
The official [subagent documentation](https://learn.chatgpt.com/docs/agent-configuration/subagents)
describes native delegation, follow-ups and result collection. Applicable skill
instructions can request delegation, but managed/user restrictions still govern.

Delegate independent workstreams to separate invocations, at most three and within
the exposed capacity. Record returned host identities in the collection registry;
map path-like identities to valid helper labels without claiming a label creates
independence. Give each investigator an isolated directory, permitted tools,
settled brief, assigned questions and the [packet contract](../investigation-packet.md).
Keep shared case writes with the coordinator.

Use the native wait/follow-up/stop operations actually available. Stopping the
collection helper rejects late results; it does not terminate agents. If native
cancellation is unavailable, disclose in-flight work. Do not change configuration,
spawn external Codex CLI processes or invent tools to obtain missing delegation.
Sequential investigation remains usable; an unavailable separate checker leaves
a draft. This adapter is capability guidance, not a cross-client acceptance claim.
