## Changes

- Natural-language research purpose guides investigation, mechanisms and examples;
  the existing schema-2 purpose field and ordinary-language default are retained.
- Skill guidance preserves concrete constraints and separates the subject/edition
  of each supporting source clause.
- The brief renders readable supporting/counter facts plus authored explanations,
  implications, qualifications and gaps.
- Comparisons examine consequential alternatives and staying with the current
  option without equal-source quotas or unsupported equivalence.
