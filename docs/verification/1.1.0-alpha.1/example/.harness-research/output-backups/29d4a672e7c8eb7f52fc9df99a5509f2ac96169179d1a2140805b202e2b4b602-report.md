# Meridian vs Boreal for an internal inventory application

> Draft — independent review is pending.

## Choose around deployment and contention

This is a controlled exercise using supplied fictional documentation; it is not guidance for a real database deployment. No network source or workload was tested.

For a single application instance with modest writes, Meridian is a candidate. When several application instances need shared data or concurrent writers, Boreal is a candidate, subject to contention and tuning checks. ## What the concurrency statements actually allow

Meridian permits one writer per database; readers can continue during a write only when journal mode is enabled. Its documented candidate workload is one application instance with modest writes, and a shared filesystem requires locking validation. ([f-2b671e92b1f9c12e72ed23d5055c416159a1f3417e4a4e8b](evidence.md#f-2b671e92b1f9c12e72ed23d5055c416159a1f3417e4a4e8b), [f-609c7f001d477435a02859d84d669eaa3b7da07e2349cf9b](evidence.md#f-609c7f001d477435a02859d84d669eaa3b7da07e2349cf9b), [f-1e08dc0b3a70a953840b93c441f067844c282a92abc1d62b](evidence.md#f-1e08dc0b3a70a953840b93c441f067844c282a92abc1d62b), [f-212228958e6e8643b8199cbcb0c6d84aa89c183c753f922a](evidence.md#f-212228958e6e8643b8199cbcb0c6d84aa89c183c753f922a))

Boreal serves several application instances over the network and supports concurrent writers. Conflicting updates may wait or retry, so this is a capability difference rather than evidence of better throughput for the inventory app. Connection limits and transaction behavior require workload-specific tuning. ([f-b78fe11312529141fc9bb01de42aa6ec7c6efde2c991cafe](evidence.md#f-b78fe11312529141fc9bb01de42aa6ec7c6efde2c991cafe), [f-a120e72417922aee2093261e703aa38c5cffef1ad69eb927](evidence.md#f-a120e72417922aee2093261e703aa38c5cffef1ad69eb927), [f-f5accb58347e9c81b3fe6f31134798b5404ca644c8970723](evidence.md#f-f5accb58347e9c81b3fe6f31134798b5404ca644c8970723), [f-763534c5b1514b6d1e947ed7dc0c0d402c30fa6790b40f2e](evidence.md#f-763534c5b1514b6d1e947ed7dc0c0d402c30fa6790b40f2e), [f-7d4911a64fa83bc899ad32e470d240ac6e077492ecfe8d9f](evidence.md#f-7d4911a64fa83bc899ad32e470d240ac6e077492ecfe8d9f))

## Recovery and access still need an owner

For Meridian, use its backup interface or stop writes before copying: an open-file copy may be incomplete. Access protection belongs to the application and operating system because no database server is exposed. ([f-02dde3dbb82c3cd28e38115587480c8d124d309ab422e313](evidence.md#f-02dde3dbb82c3cd28e38115587480c8d124d309ab422e313), [f-03485d1e334bd2ead354ef53cf32afe2d4fe8401091ad66b](evidence.md#f-03485d1e334bd2ead354ef53cf32afe2d4fe8401091ad66b))

For Boreal, configure access control, install supported updates, schedule backups, test restores and monitor the service. Someone must own recovery. A logical export is available; high availability requires extra configuration and does not promise uninterrupted failover in the supplied fixture. ([f-4f07a22ea780bb44c1aa6d87d2aa9773bf1149b4decaa618](evidence.md#f-4f07a22ea780bb44c1aa6d87d2aa9773bf1149b4decaa618), [f-d3e66b5ebd86176707efb16b3f772fec81f23f4351239997](evidence.md#f-d3e66b5ebd86176707efb16b3f772fec81f23f4351239997), [f-af55ed278fd8bc17e9cbfff6f95bf7429bb0ffd63045b107](evidence.md#f-af55ed278fd8bc17e9cbfff6f95bf7429bb0ffd63045b107), [f-db5459e93dd8f6d73cfcb7b3b70099d4bfd5f2d6a934ebbf](evidence.md#f-db5459e93dd8f6d73cfcb7b3b70099d4bfd5f2d6a934ebbf))

## What would change the decision

Neither fixture supplies comparative throughput measurements, and Boreal supplies no operating-cost figures. These materials do not establish a measured performance or cost winner. ([f-763534c5b1514b6d1e947ed7dc0c0d402c30fa6790b40f2e](evidence.md#f-763534c5b1514b6d1e947ed7dc0c0d402c30fa6790b40f2e), [f-7d4911a64fa83bc899ad32e470d240ac6e077492ecfe8d9f](evidence.md#f-7d4911a64fa83bc899ad32e470d240ac6e077492ecfe8d9f))

The missing inputs are actual instance count, conflicting-write behavior, filesystem topology, recovery objectives, restore evidence and operating ownership. Resolve these before making an unconditional recommendation.
