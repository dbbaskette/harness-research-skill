# Meridian vs Boreal for an internal inventory application

> Draft — independent review is pending.

Audience: Application engineers. Purpose: Help select an operating approach for a small internal app; explain what would change the choice.

## Start with the deployment shape

For a single application instance with modest writes, Meridian is a candidate. When several application instances need shared data or concurrent writers, Boreal is a candidate, subject to contention and tuning checks. ([f-1bac23d9aac4a8ca1c1934ce8b9a8eae3694b29a495ec074](evidence.md#f-1bac23d9aac4a8ca1c1934ce8b9a8eae3694b29a495ec074), [f-2b671e92b1f9c12e72ed23d5055c416159a1f3417e4a4e8b](evidence.md#f-2b671e92b1f9c12e72ed23d5055c416159a1f3417e4a4e8b), [f-212228958e6e8643b8199cbcb0c6d84aa89c183c753f922a](evidence.md#f-212228958e6e8643b8199cbcb0c6d84aa89c183c753f922a), [f-877913d109b7b64c747c0165764dbb3327d781c7a11817ca](evidence.md#f-877913d109b7b64c747c0165764dbb3327d781c7a11817ca), [f-b78fe11312529141fc9bb01de42aa6ec7c6efde2c991cafe](evidence.md#f-b78fe11312529141fc9bb01de42aa6ec7c6efde2c991cafe), [f-a120e72417922aee2093261e703aa38c5cffef1ad69eb927](evidence.md#f-a120e72417922aee2093261e703aa38c5cffef1ad69eb927), [f-f5accb58347e9c81b3fe6f31134798b5404ca644c8970723](evidence.md#f-f5accb58347e9c81b3fe6f31134798b5404ca644c8970723))

Meridian shared-filesystem locking requires validation; Boreal concurrent writers can still wait or retry, and its connection and transaction settings need workload-specific tuning. ## Keep these qualifications

An embedded database removes the separate service in this comparison, but it does not remove backup or access responsibilities. A separate service adds explicit update, monitoring, access-control and recovery duties. ([f-1bac23d9aac4a8ca1c1934ce8b9a8eae3694b29a495ec074](evidence.md#f-1bac23d9aac4a8ca1c1934ce8b9a8eae3694b29a495ec074), [f-877913d109b7b64c747c0165764dbb3327d781c7a11817ca](evidence.md#f-877913d109b7b64c747c0165764dbb3327d781c7a11817ca), [f-02dde3dbb82c3cd28e38115587480c8d124d309ab422e313](evidence.md#f-02dde3dbb82c3cd28e38115587480c8d124d309ab422e313), [f-03485d1e334bd2ead354ef53cf32afe2d4fe8401091ad66b](evidence.md#f-03485d1e334bd2ead354ef53cf32afe2d4fe8401091ad66b), [f-4f07a22ea780bb44c1aa6d87d2aa9773bf1149b4decaa618](evidence.md#f-4f07a22ea780bb44c1aa6d87d2aa9773bf1149b4decaa618), [f-d3e66b5ebd86176707efb16b3f772fec81f23f4351239997](evidence.md#f-d3e66b5ebd86176707efb16b3f772fec81f23f4351239997), [f-db5459e93dd8f6d73cfcb7b3b70099d4bfd5f2d6a934ebbf](evidence.md#f-db5459e93dd8f6d73cfcb7b3b70099d4bfd5f2d6a934ebbf))

Meridian open-file copies can be incomplete. Boreal high availability needs additional configuration and the fixture does not promise uninterrupted failover. ([f-02dde3dbb82c3cd28e38115587480c8d124d309ab422e313](evidence.md#f-02dde3dbb82c3cd28e38115587480c8d124d309ab422e313), [f-af55ed278fd8bc17e9cbfff6f95bf7429bb0ffd63045b107](evidence.md#f-af55ed278fd8bc17e9cbfff6f95bf7429bb0ffd63045b107))

Neither fixture supplies comparative throughput measurements, and Boreal supplies no operating-cost figures. These materials do not establish a measured performance or cost winner.
