# Meridian DB — synthetic supplied fixture

This document describes an invented product for a controlled skill test. It is not real product guidance.

Meridian embeds in the application's process and stores data in one local file. It permits one writer at a time per database. Readers can continue during a write transaction when journal mode is enabled. The operator must validate filesystem locking before using a shared filesystem.

A backup taken by copying the open database file can be incomplete; use the backup interface or stop writes first. There is no built-in network authentication because Meridian exposes no database server. The application and operating system must restrict file access.

Meridian is suitable for a single application instance with modest write traffic. No comparative throughput measurements are provided by this fixture.
