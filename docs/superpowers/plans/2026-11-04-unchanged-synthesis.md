# Explicit unchanged synthesis saves

Companion portion of Marketing Studio audit Week 5, issue dbbaskette/marketing-studio#318.
Add an opt-in unchanged-save contract; existing callers keep revision-based behavior.
Preserve independent review only after validating the full dossier, source/original and
immutable snapshot bytes, permissions, author/reviewer independence, audience, purpose,
scope, topic/collection provenance and current protocol/guidance/runtime identities.

Use a bounded project-local context file with protocol, guidance and independence
identities supplied by the actual host. Hash executable and reference bytes locally.
Return an explicit saved/no-change receipt under the existing project lock. Reuse never
retroactively adopts a legacy review. Internal schema 3 refuses old runtimes while the
portable synthesis/output format remains schema 2.

Verify repeated saves, all identity invalidations, missing/tampered inputs, concurrent
duplicates, old-call compatibility, ordinary runtime-tree confinement and installer
acceptance using disposable synthetic cases. Publish a canonical companion PR; the
Marketing Studio integration may require the capability only after a supported release
is pinned and tested. Never edit an installed skill copy.
